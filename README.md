# FortiPass – Secure Password Manager (Frontend Only)

A simple React.js web app to securely store and manage passwords locally using browser's localStorage. No backend or user login — all data stays on your device.

## Live Demo
[https://fortipassspmf.netlify.app/](https://fortipassspmf.netlify.app/)

## Features
- Add, edit, and delete passwords  
- Data saved in localStorage for persistence  
- Responsive UI with React and Tailwind CSS  

## Tech Stack
- React.js  
- Tailwind CSS  
- localStorage API  

## How to Run
1. Clone the repo  
2. Run `npm create vite@latest`  
3. Run `npm run dev`  
4. Open [http://localhost:3000](http://localhost:3000) in your browser
